# GTTC BELAGAVI COLLEGE FAQ CHATBOT — 8 SLIDES

## Slide 1 — Title
GTTC BELAGAVI COLLEGE FAQ CHATBOT
IP / NLP Lab — 3rd Project
Python + Basic NLP

## Slide 2 — Definition & Problem Statement
A text-based chatbot that answers common student questions about GTTC Belagavi.
Problem: students repeatedly need information about timings, courses,
admissions, fees, contact, website, exams and training.

## Slide 3 — Objectives
- Build FAQ knowledge base
- Preprocess input
- Tokenize questions
- Handle stopwords
- Recognize keywords/patterns
- Return predefined responses
- Detect simple sentiment
- Demonstrate NLP analysis

## Slide 4 — NLP Techniques
1. Tokenization
2. Stopword handling
3. Keyword / Regex pattern matching
4. Intent classification
5. Predefined response generation
6. Positive / negative / neutral sentiment
7. Fallback for unknown questions

## Slide 5 — System Flow
Input Text

## Slide 7 — Sample Demonstration
Input: What courses are available?
Output: GTTC Belagavi lists long-term diploma programmes including
Tool & Die Making, Precision Manufacturing, Automation & Robotics and AIML.

Input: Tell me about AIML.
Output: GTTC Belagavi lists a Diploma in Artificial Intelligence and Machine Learning.

Unknown input:
Output: Sorry, I couldn't find an answer... Try a supported FAQ.
